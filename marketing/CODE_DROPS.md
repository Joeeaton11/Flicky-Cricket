# Code drops — for the marketing team

Codes posted on Instagram/TikTok/YouTube that players type into the game (Settings → ENTER A CODE).
We reward **watching our posts**, never the follow itself (Apple 3.2.2 and Meta rules), so posts must not say
"follow to get the code" — say "here's a code" and "follow so you don't miss the next one".

| Code | Reward | Live | Ends | Status |
|---|---|---|---|---|
| FLICKY100 | 100 gems | 17 Nov 2026 | 30 Nov 2026 | LIVE — use with the first Instagram post |

Notes
- Each player can use a code once. A player who already has the game open must close and reopen it once before a new code works.
- New codes are added in `site/live/config.json` → `settings.codes.drops` (no app update). Caps: 500 gems, 10,000 coins, bag up to gold.
- Referral codes (6 letters, from INVITE MATES) also work in the same box; launch "double rewards" for referrals is waiting for store approval.
