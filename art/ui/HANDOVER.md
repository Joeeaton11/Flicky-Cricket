## RULE #1 FOR EVERY GROUND / SCENE (Joe, Oct 28) — never break this
Every ground design follows the game's layout EXACTLY, always: field oval (centre 0.50W / 0.60H, radii 0.46W / 0.335H → top 26.5%, bottom 93.5%), pitch (0.50–0.665H, widths 0.076W top / 0.116W bottom), scoreboard box (0.107–0.893W, 7.3–14%H), BEST pill (bottom centre) and name plate (bottom left). ## How each screen goes

1. **Capture** the current screen at phone size (390×844) with Playwright from `flicky-cricket.html`. One combined image per check. Read the screen's HTML/CSS/JS so the design keeps every real element and number.
2. **Design** it on the Design artifact canvas (Artifact quickstart, intent `design`): the current screen beside 2–3 redesign options at phone size. Joe picks, comments and iterates there.
3. **Build** the signed-off design into `flicky-cricket.html`, matching the canvas. Change only that screen. Check it at phone size, no console errors, then commit and push to **main** (GitHub Pages deploys only from main; check with `gh run list -R Joeeaton11/Flicky-Cricket`).
4. Note decisions and lessons in this file.

## Ground recipe (use for every new ground)
Each ground is NEW: fresh background, own props, own lettering/HUD skin. Only the camera and the game layout carry over.
1. **Read the layout** (don't move it): field oval FIELD_CY .60 / RX .46 / RY .335; pitch 0.50–0.665 H, widths 0.076/0.116 W; board top H×0.091; BEST + ball strip + pause under the board; name plate bottom-left.
2. **Plate** (Figma generate_image, gemini-3.1-flash-image, 1024×2048): "Crisp polished 3D-painted casual game art like Clash of Clans / Hay Day / Royal Match: BIG CHUNKY simplified shapes, bold clean dark outlines, glossy highlights, saturated, NO haze/blur/tiny noise" + "HIGH AERIAL CAMERA PULLED BACK" + "a TALL vertical ellipse, height 1.7× width, 5% in from each side, 27%–93% down, plain empty surface, its edge a kerb/rope ring" + what surrounds it top band / sides / bottom corners. Download via get_screenshot enableBase64Response → copy the saved PNG.
3. **Upscale 4×**: `art/grounds/tools/upscale4x.py` (Real-ESRGAN animevideov3 via ONNX; build the model once with esrgan_to_onnx.py from the .pth on GitHub releases). ~20 s.
4. **Fit, never warp**: detect the painted field (sand/grass mask, connected component at the centre); solve ONE uniform scale + offset so the painted field + kerb sit inside the coded oval + kerb (see Gully v6 numbers); crop to 1170×2532; paint out the painted kerb outside the coded oval (inpaint) if it would show; the field and boundary are then drawn in code on the exact oval (cached per size), with shading that follows the painting's light direction.
5. **Sprites** on #00FF00 sheets: crowd/props if needed; players = turnaround (front, 3/4 front, side, 3/4 back, back) ×4 fielders + run + dive + catch; batter from behind (stance, backlift, follow-through, defend/drive/pull/cut/sweep, walk-off, bat raise) in plain navy so kit colours recolour; bowler (run, leap, release, follow); umpire (idle/out/four/six); keeper. Older-teen/young-adult proportions, "cool not cute" (Brawl Stars). Key with gn=g−max(r,b) ramp 25→85, keep only the largest component + pieces inside its box, anchor at the feet.
6. **Words + HUD skin**: FOUR!/SIX!/CAUGHT!/BOWLED! + YOU WON!/SO CLOSE!/OUT!/NEW BEST! as heavy italic slab lettering in the ground's materials, no background shapes; scoreboard frame, tin plate, hanging banner, milestone card in the ground's style.
7. **Files**: art in `assets/<ground>/` loaded on demand (`gullyLoadArt` pattern); keep pixel-read or CSS-mask images embedded (batter sprites, words). `npm run build` copies assets into www.
8. **Check**: layout overlay (debug.py), phone sizes 375×667 / 390×844 / 430×932, a played innings with no console errors, a throttled perf run; then push and note in this file.
Credits: a ground with the full kit ≈ 6–8 Figma credits; a reskin reusing the Gully crew ≈ 2–3.
