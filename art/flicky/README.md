# Flicky — character layers

Flicky is always a separate transparent layer on top of a league's background, never painted into it, so he can be changed or animated without touching the scenery.

Source sheets: Figma "Flicky Cricket — Logo & Mascot", nodes 47:191 (turnaround) and 48:191 (expressions).

| File | Use |
|---|---|
| flicky-default.png | **Default look**: both eyes open, waving |
| flicky-wink.png | Cheeky moments (big six, results, ads) |
| flicky-celebrate.png | Wins, rewards, Home |
| flicky-shocked.png | Near misses, close finishes |
| flicky-dizzy.png | Out / lost |
| flicky-front / three-quarter / side / back.png | Turnaround reference for new poses |

## Rules
- Round, smooth glossy cherry red (~#C8102E), no leather texture; double cream stitched seam to his right of the face.
- **Both eyes open by default**; the wink is an expression, not his face.
- Red arms and round fists, red trainers with white soles, toe caps and laces.
- No gloves or pads by default. Kit from the Kit screen (bat, gloves, pads, helmet, shoes) can be layered on him later, so Home shows what the player has equipped.
- New poses: render him alone on #00FF00 and key him out; match these sheets.
